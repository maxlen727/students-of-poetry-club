# 诗文社的学生

*献给我的一位朋友*

这个项目是我一直以来想做的。在我还在上高中的时候，有位好朋友向我提到了“诗词娘” Galgame 的想法，苦于时间有限，承诺要帮忙一起做的东西一直没有交付，后来我们渐渐忘记了这件事，想法也搁置了。

现在我希望趁假期还有空来把这款游戏完成，并准备给朋友一个小惊喜（嘿嘿

游戏的构想已经较最初时变化了很多，困于个人能力的限制，我妥协了很多。

但这仍然是我想做的东西！希望玩到她的人都可以开开心心！希望有更多的人能发现诗词之美。

另外感谢这个可爱的时代：

- Godot: 简单易用的游戏引擎，让想法能够化为实体
- Dialogic: 直观方便的对话插件，极大简化了开发流程
- [甘茶の音楽工房](https://amachamusic.chagasi.com/index.html)： 提供了本游戏大部分 BGM
- ChatGPT: 这可是我们团队(?)最能干的画师！
- Gemini: 对剧本提出了一些修改意见，以及 nano banana 修图
- Deepseek: 帮助设计了大纲
- ElevenLabs: 强大的 SFX 生成平台，提供了大部分的音效
- 猫啃网： 提供了无版权的字体，以及漂亮又契题的猫啃什锦黑
- Claude: 对代码提供了很多帮助
- ComfyUI & Anima: 炼丹炉，炼出了一些有意思的丹

感谢制作过程中所有提供帮助的朋友们：

- 冬之寒： 对剧本提出了修改意见以及角色选型上的建议
- 冬旭： 对剧本提供了修改意见以及角色选型和素材处理的帮助
